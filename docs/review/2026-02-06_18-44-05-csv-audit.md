## 偏差审计

### 1) 实现偏差（Implementation Deviation）
- **发现**：`FRUX` 中声称已完成的多个 Admin 页面（Proxy/Binding/Hydration 等）在运行态出现“未指定组件”错误，页面无法渲染。
- **证据**：`docs/review/screenshots/2026-02-06_18-44-05/proxy-easy-import-broken.png`、`token-proxy-binding-broken.png`、`hydration-broken.png`、`ops-navigator-broken.png`。
- **判定**：CSV 状态 `DONE` 与真实运行态不一致，存在功能闭环缺口。

### 2) 文档偏差（Documentation Deviation）
- **发现**：历史 CSV 对于“已 push/未 push”存在大量受限记录，文档层面说明完整，但“实际远端状态”未形成独立追踪清单。
- **表现**：PPOOL/RAPI 多处 `validation_limited: git push failed`，但最终 CSV 仍统一 `DONE`。
- **判定**：文档记录了限制，但“发布态可追溯性”不足（是否最终补 push 不可一眼确认）。

### 3) 测试偏差（Testing Deviation）
- **发现**：RAPI 226 条里 225 条 `Test_Method` 标注为 manual，导致自动化验证密度表达失真（实际项目已有大量 vitest）。
- **判定**：测试执行有做，但 CSV 的 `Test_Method` 字段表达粒度偏粗，不利于后续按能力域筛选回归。
- **附注**：最新 baseline (`npm run test:all`) 通过，说明“测试资产存在”，但 CSV 未充分结构化反映。

### 4) 体验偏差（UX Deviation）
- **发现**：
  - 多页面中英文混排仍存在（导航与页面名如 `Import Urls` / `Hydration Ops` / `Token Proxy Bindings`）。
  - i18n missingKey 控制台噪声密集（每页大量重复）。
  - `/favicon.ico` 每页 400，形成固定噪声。
- **判定**：与“全站统一文案/反馈语义”目标存在残留差距。

## 流程一致性检查
- 优点：3 份 CSV 的 `ID -> commit` 映射完整（missing=0）。
- 风险：存在“非 CSV 映射行为提交”（19 条），尤其热修提交未回填 issue，削弱契约治理闭环。

## 结论
- 历史 CSV 在“任务颗粒度和落盘记录”方面总体可追溯；
- 但在“运行态真实可用性（尤其 Admin 自定义页面）”上，`DONE` 状态存在偏乐观标注；
- 本轮应优先把 **Admin 自定义页面组件注册/打包链路** 修到运行态真通过，再更新新 CSV 状态。
